# Tailwind Random Color

เว็บแอปพลิเคชันสำหรับสุ่มดูสีและคัดลอกคลาสของ Tailwind CSS (v4) สร้างขึ้นมาเพื่อเป็นเครื่องมือช่วยนักพัฒนาในการหาสีและ Gradient ที่ใช่ได้อย่างรวดเร็ว  
**_(ที่จริงแล้วผมแค่ขี้เกียจและนึกไม่ออกว่าจะใช้สีอะไรดี)_**

## ฟีเจอร์หลัก (Features)

- **สุ่มสีง่ายๆ:** ปัดซ้าย/ขวา (Swipe) บนมือถือ หรือใช้ลูกกลิ้งเมาส์ (Scroll) บนคอมพิวเตอร์ เพื่อสุ่มสี
- **คัดลอกโค้ดทันที:** ปัดขึ้น (Swipe up) เพื่อ Copy โค้ดคลาสของ Tailwind ไปใช้งานได้เลย
- **3 โหมดการใช้งาน:** - `Solid`: สีพื้นฐาน
    - `Gradient`: ไล่สีเฉดเดียวกัน (อ่อนไปเข้ม)
    - `Mix Grad`: ไล่สีแบบสุ่ม 2 สี
- **ตัวกรองสี (Filters):** กรองสีที่ต้องการได้ตามหมวดหมู่ (Light, Dark, Cold, Warm)
- **ทิศทาง Gradient:** สามารถเลือกทิศทางการไล่สีได้อิสระ

## เทคโนโลยีที่ใช้ (Tech Stack)

- HTML5
- Tailwind CSS v4 (ผ่าน CDN)
- Vanilla JavaScript

## วิธีใช้งาน (How to use)

ไม่ต้องติดตั้งอะไรเพิ่มเติม เพียงแค่นำไฟล์ไปรันก็ใช้งานได้ทันที:

1. ดาวน์โหลดหรือ Clone โปรเจกต์นี้
2. เปิดไฟล์ `index.html` ผ่านเว็บบราวเซอร์ของคุณ
